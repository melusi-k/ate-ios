## Keeping the map useful

Link a new canonical contract here when it fills a real gap. Keep an owner and status in substantive designs. Correct historical evidence with a dated addendum; do not replace old findings with an invented pass. Avoid another FAQ, acceptance checklist or release procedure when the owning document already exists.

The current architecture/policy additions are proposals. Their presence in this map does not approve a first Intelligence Foundation implementation slice or change existing CI/release gates.
