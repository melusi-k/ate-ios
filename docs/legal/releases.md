# Release notes

_Generated from the app's changelog._

Ate uses two stages: Pilot for an invited group proving the cooking loop, then Launch for general users. A "Pilot candidate" is a build to test, not stage approval. Version numbers identify software, not release stages. Historical TierA tags remain valid compatibility links. `latest-build` is an internal artifact; `latest-beta` retains its separate validation gate. See [release gates](https://github.com/melusi-k/ate-ios/blob/main/docs/LAUNCH_GATES.md) for the decision criteria.

Download builds from the [releases page](https://github.com/melusi-k/ate-ios/releases). Install help: [Support](support.html).
